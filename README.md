# 🌊 Krillion: Multilang

Многоязычная игра-аналог **Krillion**, где побеждает **самый редкий и нестандартный ответ**, а не самый популярный. Отвечать можно на **любом языке** (русском, английском, испанском, немецком, японском и др.) — движок автоматически переводит ответ, проверяет его по смыслу и начисляет очки редкости.

## ✨ Основные возможности

- **Многоязычный ввод и автоперевод (`Stage 0`)**:
  - Определение языка и перевод через Google Translate с резервным переключением на MyMemory, встроенный офлайн-словарь (`OFFLINE_TRANSLATIONS`), фонетическую транслитерацию кириллицы и межъязыковые ссылки Википедии (`langlinks`).
- **Семантическая оценка в 5 этапов (`evaluateAnswer`)**:
  1. Точное совпадение, синонимы и морфология (`exact`, `alias`, `fuzzy` на базе Damerau–Levenshtein).
  2. Распознавание редких разновидностей и подвидов (`subtype` — например, *императорский пингвин* или *королевская кобра* с повышением уровня редкости).
  3. **Open-World проверка** через английскую и русскоязычную Википедию (`unique_discovery`) для редких правильных ответов, которых нет в базовом словаре.
  4. Семантическое расширение через **Datamuse API** (`syn` и `primary_rel`).
  5. Опциональная проверка через **Gemini API** (при наличии `GEMINI_API_KEY`).
- **Диагностика близости по теме**:
  - Если ответ не засчитан, но близок по смыслу (например, млекопитающее вместо яйцекладущего, сплав вместо чистого металла, страна другого континента), игра показывает процент тематической близости и объясняет, почему вариант не подошёл.
- **6 уровней редкости (глубина погружения)**:
  - 🦠 `Plankton` → 🧠 `Too Clever` → 🐟 `Schooler` → 🦑 `Rare` → 🐙 `Deep Cut` → 🐋 `One in a Krillion`.

## 🚀 Быстрый старт

Требуется **Node.js >= 22** (используется встроенный `fetch`).

```bash
node server.js
```

После запуска игра доступна по адресу: **http://localhost:3456**

### Опционально: Gemini AI Judge

```bash
GEMINI_API_KEY=ваш_ключ node server.js
```

## 📁 Структура проекта

- `server.js` — HTTP-сервер, API (`/api/health`, `/api/dives`, `/api/evaluate`, `/api/translate-check`) и многоязычный семантический движок.
- `data/prompts.js` — категории погружений (`DIVES`, `PROMPTS`), уровни редкости (`RARITY_TIERS`), предметные валидаторы (`PROMPT_DOMAIN_VALIDATORS`) и офлайн-словарь (`OFFLINE_TRANSLATIONS`).
- `public/` — клиентский интерфейс (`index.html`, `styles.css`, `app.js`).
